Networking - VPC

A VPC contains subnets, route tables, gateways, and network controls that decide how resources communicate.

↔
THE MAIN IDEAPublic resources can have a route to an Internet Gateway. Private instances normally use a NAT gateway only for outbound IPv4 internet access.
