EC2 Fundamentals

An EC2 instance combines an image, hardware size, network placement, storage, and firewall rules.

▣
THE MAIN IDEAThe AMI supplies the operating system. The instance type supplies CPU and memory. The security group controls network traffic.

AMI→Instance type→Subnet→Security group

What words should guide you?

Instance firewall → security group. Subnet firewall → network ACL.
