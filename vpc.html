What to learn

A subnet CIDR must fit inside the VPC CIDR. Every extra prefix bit doubles the number of possible equal-size subnets and halves each subnet’s address capacity.

  • AWS IPv4 subnets support sizes from /16 through /28.
  • AWS reserves five IPv4 addresses in every subnet.
  • Public versus private is determined mainly by routing and address assignment—not by the CIDR itself.
subnet count = 2^(subnet prefix − VPC prefix) addresses = 2^(32 − subnet prefix)
