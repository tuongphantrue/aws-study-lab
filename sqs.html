What to learn

Receiving an SQS message does not remove it. The message becomes temporarily invisible while a consumer processes it, and the consumer deletes it only after success.

  • If processing fails or the worker disappears, the message becomes visible again.
  • Standard queues use at-least-once delivery, so consumers should be idempotent.
  • A redrive policy can move repeatedly failing messages to a dead-letter queue.
