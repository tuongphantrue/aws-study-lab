Storage service selector

Turn workload requirements into a defensible choice among Amazon S3, EBS, EFS, and FSx.

Workload requirements

Recommended storage

Exam decision rules

  • S3 is object storage with enormous scale, regional durability, and lifecycle classes.
  • EBS is block storage for EC2 and is scoped to one Availability Zone.
  • EFS provides elastic shared NFS storage across multiple AZs.
  • FSx is chosen when a managed specialized file system is required.

Common distractor

Do not choose EBS simply because the data is “a file.” The deciding factor is how the application mounts and accesses the data.
