What to learn

Concurrency is the number of requests a function is processing at the same time. A useful estimate is request rate multiplied by average duration.

  • Reserved concurrency caps and protects capacity for a function.
  • Provisioned concurrency pre-initializes environments to reduce cold-start latency.
  • Provisioned concurrency does not make a function infinitely scalable; requests beyond it can use on-demand environments until another limit is reached.
concurrency ≈ requests per second × average duration in seconds
