Global routing and delivery

Decide when a design needs Route 53, CloudFront, Global Accelerator, or a regional load balancer.

Delivery requirements

Recommended path

Know the boundaries

  • Route 53 makes DNS routing decisions.
  • CloudFront caches HTTP content and terminates requests at edge locations.
  • Global Accelerator provides static anycast IPs and moves TCP/UDP traffic onto the AWS global network.
  • ALB/NLB distributes traffic to healthy targets inside a Region.

Question clue

“Cache”, “static IP”, and “DNS policy” are not interchangeable. Each phrase points to a different service layer.
