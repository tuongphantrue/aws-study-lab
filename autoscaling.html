What to learn

Target tracking behaves like a thermostat: it changes desired capacity to keep a chosen metric near a target value.

  • Minimum and maximum capacity are hard bounds.
  • Scaling out is usually more aggressive because availability has priority.
  • Instance warmup prevents freshly launched capacity from immediately distorting the next scaling decision.
rough desired capacity ≈ current load / target capacity per instance
